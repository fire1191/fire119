신청관리 구글 시트 열기 →

엑셀 내려받기

시트 위쪽 소방교육 관리 → 신청 명단 엑셀 내려받기를 누르세요.

메뉴가 보이지 않으면 시트를 새로고침해 주세요. 전체 자료는 파일 → 다운로드 → Microsoft Excel(.xlsx)에서도 받을 수 있습니다.

다음 교육에도 재사용

  1. 소방교육 관리 → 접수 마감
  2. 다음 교육 준비 → 제목과 날짜 입력
  3. 교육설정 탭에서 시간과 안내문 확인
  4. 소방교육 관리 → 접수 열기

이전 신청 명단은 그대로 남습니다. 신청 페이지 주소와 QR은 바뀌지 않습니다.
