# 소방안전교육 신청 페이지 (구글 시트 연결판)

## 현재 사용 방식

GitHub Pages의 고정 주소/QR에서 신청 화면이 바로 열립니다. Google 계정 쿠키를 보내지 않는 요청으로 Apps Script에 저장·조회하여 다중 로그인으로 인한 화면 열기 오류를 피합니다. 신청 내용은 아주대학교 학교 계정 소유의 비공개 구글 스프레드시트에 저장합니다. Supabase는 사용하지 않습니다.

- 사번·이름 직접 입력 후 소속·이메일·참여 시간 선택
- 교직원 명단 조회 또는 본인 인증을 진행하지 않음
- 관리자는 학교 계정으로 구글 시트를 열어 신청 명단 조회
- 시트의 `소방교육 관리 → 신청 명단 엑셀 내려받기`로 전체 교육 명단과 설정을 .xlsx 저장
- 개인정보 안내: 시설팀, 내선 2087, 교육 종료 후 1개월 보유
- 개인정보 자동 삭제는 설정하지 않았으므로 관리자가 보유기간 종료 후 직접 삭제

신청 페이지: https://leg2900-arch.github.io/fire-safety/

관리 안내 및 QR: https://leg2900-arch.github.io/fire-safety/admin.html

## 구성

`site/`는 GitHub Pages에 배포되는 실제 신청 화면·미리보기·관리 안내입니다. `google-apps-script/Code.gs`와 `Index.html`은 학교 계정의 Apps Script 프로젝트에 저장합니다. GitHub에는 프로그램 코드만 보관하며 실제 응답은 올리지 않습니다. 구글 시트 ID 자체는 접근 권한을 주지 않으며, 시트는 소유자에게만 공개되어 있습니다.

## 연결 및 게시

1. Apps Script에 `Code.gs`, `Index.html`을 저장합니다. Code.gs의 `SHEET_ID`는 실제 신청관리 시트입니다.
2. 웹 앱을 소유자 계정으로 실행하도록 배포합니다. 신청자의 구글 로그인 없이 직접 정보를 입력받으려면 접근 범위는 `모든 사용자`입니다. 현재 교육 안내, 신청 저장, 사번·이름 일치 시 해당 신청의 이름·교육일자·참여시간·신청일시 조회를 제공합니다. 전체 명단은 공개하지 않습니다.
3. 배포된 `/exec` 주소를 `site/config.js`의 `appsScriptUrl`에 넣습니다.
4. GitHub의 main에 변경 사항을 올립니다. Actions가 `site/`를 자동 게시합니다.
5. 관리 시트의 `교육설정` 탭에서 날짜·시간·개인정보 안내를 확인하고 `소방교육 관리 → 접수 열기`를 누릅니다.
6. QR 접속 → 시험 신청 → 시트 기록 → 엑셀 내려받기 순서로 실제 연결을 확인합니다.

## 다음 교육에 사용

시트의 `소방교육 관리 → 접수 마감 → 다음 교육 준비`에서 새 제목·날짜를 입력합니다. 교육설정 탭에서 시간과 개인정보 안내를 확인하고 `접수 열기`를 누릅니다. 기존 명단은 교육ID와 함께 남으며, 고정 주소와 QR은 그대로입니다. 시트 메뉴가 보이지 않으면 학교 계정으로 열고 새로고침하세요.

## 보안과 기록

- 신청자는 현재 교육 안내, 신청 저장, 사번·이름 일치 시 자신의 신청 내역을 조회할 수 있습니다. 별도 본인 인증은 없으므로 타인의 사번과 이름을 아는 사람도 해당 내역을 조회할 수 있습니다.
- 관리자 메뉴 함수는 이름 끝의 `_`로 웹에서 호출되지 않도록 분리했습니다.
- 명단 시트는 외부 공개·학교 전체 공개로 바꾸지 않습니다.
- 사번은 숫자 9자리로 입력하고 텍스트로 보관해 앞자리 0을 유지합니다. 텍스트 입력의 수식 실행을 막습니다.
- 같은 교육·사번 중복 신청을 막고, 요청ID로 통신 재시도를 중복 저장하지 않습니다. 입력 사번이 실제 본인 사번인지는 인증하지 않습니다.
- 요청 처리 시 구글 서버가 기록한 신청 일시를 저장하며 한국 시간으로 표시합니다.
- `?demo=1`은 서버에 입력을 전송하지 않는 미리보기입니다.
- Google Apps Script와 Sheets의 이용 한도·학교 관리 정책이 적용됩니다. 유료 서비스는 신청하지 않았습니다.

## 라이브러리

qrcode-generator 1.4.4 (MIT), SheetJS CE 0.18.5 (Apache-2.0). 라이선스는 `site/vendor/`에 있습니다. 글꼴을 불러오지 못하면 기본 글꼴을 사용합니다.


## 연결 수정 후 확인

`?v=direct-1` 주소로 예전 화면 캐시를 피할 수 있습니다. 신청 화면 수정은 `site/index.html`, `site/app.js`에 반영합니다. 저장·조회 기능은 Apps Script의 `Code.gs`를 저장한 다음 **기존 배포 관리 → 수정 → 새 버전**으로 업데이트합니다. 새 배포를 만들면 주소가 달라져 `site/config.js`도 변경해야 합니다. 개인정보는 URL에 넣지 않고 POST 본문으로 전송합니다.
