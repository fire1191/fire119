## 운영 방식

교육장 입구에서 QR을 스캔하고 사번(숫자 9자리), 이름, 소속, 이메일, 교육 시간을 입력해 출석을 등록합니다. 사번과 이름을 입력해 해당 교육의 출석 내역을 확인할 수 있습니다. 교직원 명단 대조나 별도 본인 인증은 하지 않습니다.

화면과 QR은 이 GitHub 저장소의 site 폴더에서 관리합니다. main 브랜치에 변경을 올리면 .github/workflows/pages.yml이 GitHub Pages를 자동 게시합니다.

출석 내역은 기존 아주대학교 Google 계정의 비공개 Google Sheets에 저장합니다. GitHub 계정 변경으로 Google Sheets와 Apps Script 소유자가 바뀌지는 않습니다. 담당자에게 명단 관리까지 인계하려면 해당 Google 파일의 권한을 별도로 확인해야 합니다.

## 교육 설정 및 엑셀

관리자 화면에서 구글 시트를 엽니다. 시트의 ‘소방교육 관리’ 메뉴에서 접수 열기/마감, 다음 교육 준비, 교육명 수정, 명단 엑셀 내려받기를 사용할 수 있습니다. 교육설정 탭에서 날짜, 시간, 개인정보 안내를 수정합니다.

연결된 프로그램이 확인하는 신청명단 탭과 열 이름은 그대로 유지합니다. 화면에는 출석 등록으로 표시합니다. 개인정보 안내는 시설팀 내선 2087, 교육 종료 후 1개월 보유로 설정되어 있으며 보유기간 후 관리자가 직접 삭제합니다.

## 연결 정보

site/config.js의 appsScriptUrl은 기존 공개 웹 앱 주소이며 비밀키가 아닙니다. 전체 명단 조회는 공개하지 않고 사번·이름 일치 시 해당 내역만 돌려줍니다. 사번·이름을 아는 사람도 해당 내역을 조회할 수 있습니다. 입력 정보는 POST 본문으로 전송하며 Google 로그인 쿠키를 보내지 않습니다.

저장·조회 기능 수정 시 Apps Script의 실제 최신 코드를 확인하고 기존 배포를 새 버전으로 업데이트합니다. 새 배포를 만들면 주소가 달라질 수 있습니다. site/index.html과 site/app.js는 실제 운영 화면입니다. google-apps-script/Index.html은 과거 Apps Script 화면용이므로 운영 화면 수정에 사용하지 않습니다.

라이브러리 라이선스는 site/vendor에 포함되어 있습니다. GitHub에는 실제 명단을 올리지 않습니다.


# 소방교육 출석 등록 운영 방법

관리 시트: https://docs.google.com/spreadsheets/d/1UX9CVlKfbV-XgInlxpDLvqK-ERvqyHzjPG-IXwuDblw/edit#gid=1513564431&range=B7

출석 등록: https://fire1191.github.io/fire119/

현재 자동 운영으로 설정되어 있습니다. 교육설정 B4에 입력한 교육일(현재 2026-11-24)의 한국시간을 기준으로 1차 09:30~11:00, 2차 13:30~15:00에만 해당 차수를 등록할 수 있습니다. 교육일 외에는 등록할 수 없습니다. 시작 시각부터 등록할 수 있고, 마감 시각이 되는 순간 닫힙니다.

## 평소에는 자동으로 두세요

교육설정 탭의 B7 드롭다운에서 ‘자동’을 선택합니다. 별도로 교육 당일에 버튼을 누르거나 PC를 켜 둘 필요가 없습니다. 구글 서버가 저장할 때 날짜와 시간을 확인합니다.

## 내가 직접 열거나 닫으려면

- 지금 열기: B7을 ‘수동 열기’로 변경합니다. 날짜·시간 제한이 풀리고 모든 차수의 등록을 받습니다. 시험 등록이나 예외 운영에 사용할 수 있습니다.
- 지금 닫기: B7을 ‘마감’으로 변경합니다. 저장이 즉시 차단됩니다.
- 다시 시간표대로: B7을 ‘자동’으로 돌려놓습니다. 수동 열기와 마감은 자동으로 해제되지 않으므로 직접 자동을 선택해야 합니다.

상단 ‘소방교육 관리’ 메뉴의 ‘시간표대로 자동 운영’, ‘지금 열기 (시간 제한 해제)’, ‘지금 닫기’도 같은 기능입니다. 메뉴가 보이지 않으면 시트를 새로고침하세요.

## 등록 가능 시간을 바꾸려면

교육설정에서 1차는 B11(시작), C11(마감), 2차는 B12(시작), C12(마감)을 수정합니다. ‘09:30’, ‘13:30’처럼 24시간제 HH:mm으로 입력하세요. 마감은 시작보다 늦어야 합니다. B7을 자동으로 두어야 시간표가 적용됩니다.

교육일은 B4에서 변경합니다. 등록 시간표는 해당 날짜를 따라갑니다. A11:A20의 교육 시간 이름은 B5의 각 교육 시간 항목과 같아야 합니다. 교육 시간을 추가하면 시간표에도 같은 항목과 시작·마감을 추가하세요. 최대 10개 차수를 지원합니다.

## 변경 후 확인

출석 페이지를 새로고침해서 안내와 버튼 상태를 확인합니다. 이미 열어 둔 페이지는 약 1분 이내에 운영 상태를 다시 확인하지만, 실제 저장은 변경된 상태와 시간을 즉시 확인합니다. 등록 시간이 지나도 ‘내 출석 내역 확인’은 사용할 수 있습니다.

다음 교육은 먼저 ‘지금 닫기’를 선택하고 ‘다음 교육 준비’에서 제목·날짜를 바꾼 뒤 교육 시간과 등록 시간표를 확인하고 자동으로 변경합니다. 이전 출석 명단은 그대로 남습니다. QR은 그대로 사용합니다.

엑셀은 소방교육 관리 → 출석 명단 엑셀 내려받기에서 받습니다. 명단 저장용 탭과 열 이름은 프로그램과 연결되어 있으므로 그대로 유지하세요.
